[3] files

Your requests are files. Commit them.

Collections are folders of YAML files: version them in Git and review changes in pull requests.

Layer .env files with -e and switch environments without restarting. Edits on disk reload automatically.

[4] toolkit

Other features

autocompletion
Complete variables with $ in URLs, headers, query, auth and bodies. Header suggestions include descriptions.
url bar
Preview the resolved URL before sending. Variables turn green when resolved and red when missing.
authentication
Basic, Digest (MD5 and SHA-256) and bearer tokens, with variables allowed in every field.
responses
Highlighted JSON, an expandable tree with JSONPath filtering, headers, cookies and a timing trace.
request tabs
Keep several requests open, with unsaved changes marked.
editor & pager
Press F4 to edit a body in $EDITOR, or F3 to read it in $PAGER.
keymaps & config
Rebind actions and configure Posting with config.yaml or POSTING_* environment variables.
layouts
Resize panes and arrange the request and response vertically or side by side.
coding agents
Let agents send requests through your open Posting session with posting remote. Set it up.
nerd font icons
Icons switch on automatically in Ghostty, and anywhere else with one setting.
[5] upgrade
posting 2 → 3

Bring your HTTP collections.

Posting 3 opens your Posting 2 collections without conversion. Python scripts are preserved but aren't run, history is separate, and some settings and theme options have changed.
