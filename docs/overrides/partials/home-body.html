Posting is a keyboard-driven HTTP client. Compose requests, switch environments and read responses without reaching for the mouse. Run it on your laptop, over SSH or inside a container, and keep every request as plain YAML next to your code.

# plain files

Your requests are files. Commit them.

A collection is a folder, and each request is a short YAML file. Review changes in pull requests, share them with your team, and branch them alongside your code.

Environments are ordinary .env files. Layer several with -e, switch between them while Posting is running, and see edits on disk straight away.

# in the box

The rest of the toolkit.

autocompletion
Type $ in the URL, headers, query, auth or body to complete variable names. Header names complete too, each with a note on what it does.
url bar
Checks your work. Variables turn green when they resolve and red when they don't, and the finished URL is shown under the bar before you send.
authentication
Basic, Digest (MD5 and SHA-256) and bearer tokens, with variables allowed in every field.
responses
Pretty-printed, highlighted JSON with wrap and copy, plus headers, cookies and a timing trace for every request.
request tabs
Keep several requests open at once. Unsaved changes are marked with a dot.
editor & pager
Press F4 to edit a body in $EDITOR, or F3 to read it in $PAGER.
keymaps & config
Rebind any action. Configure Posting with config.yaml or POSTING_* environment variables.
layouts
Stack the request and response or put them side by side. Resize panes, switch to compact spacing, and click anything you like.
nerd font icons
Icons switch on automatically in Ghostty, and anywhere else with one setting.
